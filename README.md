# FavPeople — финальный проект: персональное offline-first приложение

**ФИО:** Алалин Алексей Юрьевич  
**Группа:** ПИКД Б9123-09.03.03, 5 подгруппа  
**VariantCode:** TVM-PEOPLE-MOD_E25_FAV_SORT · API: TVmaze (`https://api.tvmaze.com`)

Базовый проект (список, детали, навигация, Retrofit, Room, Hilt, Flow) сохранён и развит в
небольшое законченное приложение: внешний API — источник контента, а ценность приложения —
в личных данных пользователя и в работе без сети.

## Что добавлено
| Экран | Что там |
|---|---|
| Главный | лента из кэша Room, поиск (онлайн/офлайн), фильтры по личным данным, недавние запросы, плашка «нет сети», время обновления |
| Детали | данные из кэша + обновление, избранное, **мой статус**, **моя заметка**, **мои подборки** |
| **Моё** (новый) | личный раздел: подборки пользователя и все заметки/статусы |
| **Подборка** (новый) | состав подборки, переименование, удаление людей и всей подборки |
| **История** (расширен) | недавние поисковые запросы (тап — повторить поиск) + просмотренные люди |
| **Настройки** (новый) | TTL кэша, фоновая синхронизация, только Wi-Fi, «синхронизировать сейчас», очистка кэша, показ скрытых, сортировка, тема |

## Новые пользовательские данные (Room)
| Таблица | Сущность | Создаёт / меняет пользователь |
|---|---|---|
| `collections` | подборка (название, описание) | создать, переименовать, удалить |
| `collection_items` | **связь многие-ко-многим** подборка ↔ человек (FK + CASCADE) | добавить/убрать человека |
| `person_notes` | заметка + личный статус (Нравится / Изучить позже / Скрыть из ленты) | написать, изменить, удалить |
| `search_history` | недавние запросы | появляется при поиске, очищается |
| `view_history` | история просмотров | появляется при открытии деталей, очищается |
| `favorites` | избранное (с сортировкой по времени добавления — модификатор варианта) | ☆/★ |
| `people`, `main_list` | кэш данных API со временем загрузки `fetchedAt` | — (служебные) |

Настройки (TTL, синхронизация, сортировка, тема, показ скрытых, время последней синхронизации)
хранятся в **DataStore Preferences** — пользовательские данные в DataStore не хранятся.

## Новые сценарии
1. **Подборки** *(существенный, новая сущность + связь многие-ко-многим)* — «Моё» → «+ Создать» →
   «Любимые актёры» → открыть человека → чип с названием подборки → человек в подборке →
   экран подборки показывает состав, можно переименовать/убрать/удалить. Название проверяется
   (пустое, > 40 символов, повтор без учёта регистра). Работает без сети.
2. **Личный статус и заметка** *(влияет на поведение)* — на деталях выбрать статус и написать заметку →
   в ленте у человека появляется значок; статус «Скрыть из ленты» убирает человека из ленты и поиска
   (вернуть можно в настройках); фильтры «❤ Нравится» и «🔖 Изучить» на главном экране;
   все заметки собраны в разделе «Моё».
3. **Офлайн-режим с актуализацией и фоновой синхронизацией** *(существенный)* — данные кэшируются с
   TTL, без сети показываются сохранённые данные и плашка, поиск переключается на локальный кэш;
   WorkManager в фоне обновляет ленту и заранее скачивает людей из избранного, подборок и заметок;
   в настройках видно время последней синхронизации и можно запустить её вручную.
4. **История и недавние запросы** — экран истории с повтором поиска одним тапом.

## Как устроена offline-first часть
- **Единственный источник правды — Room.** UI подписан на `Flow` из Room (`observeMainList`,
  `observePerson`), а сеть только **обновляет** Room (`refreshMainList`, `refreshPerson`).
- **Политика актуальности (TTL)** — `CachePolicy`: если данные моложе TTL из настроек, в сеть не
  ходим; «Обновить»/Retry обновляет принудительно.
- **Без сети:** если в кэше есть данные — показываем их + плашку «Нет сети — показаны сохранённые
  данные»; если кэша нет — Error + Retry. Детали тоже открываются из кэша.
- **Поиск без сети** — по уже сохранённым людям (`LIKE` в Room) с плашкой «поиск по сохранённым данным».
- Найденные и просмотренные люди попадают в кэш; старые записи, на которые ничто не ссылается,
  удаляются через неделю (`pruneUnreferenced`), а люди из избранного, подборок, заметок и истории — никогда.

## Фоновая обработка (WorkManager)
- `SyncWorker` (`@HiltWorker`) → `OfflineSyncer`:
  1. обновить ленту, если она устарела;
  2. **предзагрузить для офлайна** детали людей из избранного, подборок и заметок;
  3. почистить старый кэш;
  4. сохранить время синхронизации (видно в настройках).
- Периодически раз в 6 часов при наличии сети (или только по Wi-Fi), с экспоненциальным повтором;
  разовый запуск — кнопкой «Синхронизировать сейчас».
- `SyncScheduler` слушает настройки (Flow из DataStore) и включает/выключает задачу.
- Без сети Worker возвращает `Result.retry()`.

## Архитектура
```
ui (Compose screens) → ViewModel (StateFlow/SharedFlow) → domain (интерфейсы репозиториев + чистая логика)
                                                         → data: Room / DataStore / Retrofit / WorkManager
```
Всё связывается через Hilt (`NetworkModule`, `DatabaseModule`, `RepositoryModule`).

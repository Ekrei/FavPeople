VariantCode: TVM-PEOPLE-MOD_E25_FAV_SORT

Модификатор варианта: MOD_E25_FAV_SORT — в избранном отдельная сортировка (по времени добавления) в рамках сессии.

Как реализовано:

- Пользователь может добавлять людей в избранное с экрана списка (кнопка-звёздочка на карточке) и с экрана деталей (кнопка «В избранное» / «Убрать из избранного»).
- Избранное хранится в памяти на время сессии (между запусками приложения не сохраняется).
- На главном экране сверху отображается блок «Избранное (сортировка по времени добавления)»: элементы отсортированы по времени добавления — сначала последние добавленные.
- Сортировка применяется только к списку избранного и только в текущей сессии.

Использованные endpoints (TVmaze API)  
URL: https://api.tvmaze.com

Список людей (List) GET /people?page=0 Загрузка первой страницы людей на главном экране (не менее 20 элементов).
Детали элемента (Detail) GET /people/{id} Загрузка деталей выбранного человека по id после нажатия на элемент списка.
